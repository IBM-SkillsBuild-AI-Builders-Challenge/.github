# 🤖 IBM SkillsBuild AI Builders Challenge

Welcome to the official GitHub organization for the **IBM SkillsBuild AI Builders Challenge** — a program where builders take on monthly challenges to design, train, and ship real AI-powered applications using IBM SkillsBuild resources and watsonx.ai / Granite models.

---

## 🚀 About the Challenge

The IBM SkillsBuild AI Builders Challenge invites developers, students, and hobbyists to:

- Learn hands-on AI/ML skills through guided labs
- Build practical projects using **IBM Granite** foundation models and **watsonx.ai**
- Tackle a new themed challenge each month
- Ship working prototypes — from sports analytics to biotech to edge computing

Whether you're new to AI or a seasoned builder, this space is where learning meets shipping.

## 🤝 How to Get Involved

1. ⭐ Star the repos that interest you
2. 🍴 Fork **hands-on-labs** and work through the current monthly challenge
3. 💡 Build your own project idea using Granite / watsonx.ai and submit it as a new repo
4. 🐛 Open issues or PRs to improve existing challenge projects
5. 👥 Check the [People](https://github.com/orgs/IBM-SkillsBuild-AI-Builders-Challenge/people) tab to connect with other builders
